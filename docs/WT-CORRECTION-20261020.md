# 사장 근무 정정 검토
직원 시간 정정·반려 후 재제출을 기존 검수 목록에서 검토한다. 정정 횟수·최근 사유·반려 사유를 표시한다. 승인/반려 요청에 화면에서 본 expectedCorrectionCount를 보내며, 반려 대화상자는 열었던 시점의 버전을 보존한다. 중복 제출은 막고 실패·성공 모두 재조회한다. 수정된 시간과 오래된 승인 화면의 경합은 백엔드가409로 거절한다.

백엔드 정정 API 업데이트가 먼저 필요하다. 신규 응답 필드는 선택적으로 읽어 이전 서버와의 조회 호환을 유지한다. 기존 정정 없는 기록은 expectedCorrectionCount=0으로 승인 가능하다. 앱에서 정정한 건의 승인에는 이 웹 업데이트가 필요하다. CI tsc/vite build를 수행한다. 실제 브라우저/기기 연결 검증은 별도다. main 병합 시 기존 개발환경 자동배포가 발생한다.
